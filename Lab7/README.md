# [Lab7](https://github.com/Unixado/McGill-ESCE307-Labs/tree/master/Lab7)
In this lab, we experimented with different controller designs to regulate the angular position of the DC Motor. We used the state space representation of the system and lsim to simulate the response of continuous linear systems to arbitrary inputs. We first defined the DC Motor, then designed an output feedback controller for angular position control. Finally, we studied the effect of model mismatch on output feedback control and designed a state feedback with an integral component to reduce the disturbance effects.
