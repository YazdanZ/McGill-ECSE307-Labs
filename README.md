## [Lab2](https://github.com/Unixado/McGill-ESCE307-Labs/tree/master/Lab2)
This Lab was about analyzing second order systems by their impulse response and transfer functions. Some activities of this lab were plotting step responses and identifying characteristics of transient responses. An open-loop unstable system was introduced that had to be stabilized by adding a gain (controller) and a feedback to the system, transforming it into a closed-loop system. The stabilized closed-loop system was then approximated using dominant pole approximation and results were analyzed.<br/>
some other areas of studies were: 
* modeling Linear Time Invariant (LTI) systems 
* different ways of defining transfer functions 
* using the Zero-pole-gain model (zpk)
* determining poles and zeros of transfer functions 
* plotting impulse and step responses
* interconnecting systems
